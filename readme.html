Google Antigravity Custom Skill v1.0

RPS UNIROW — Generator RPS OBE 2026

Modul kecerdasan buatan untuk Google Antigravity, Cursor IDE, dan Claude Code guna menyusun, mengisi, dan memformat dokumen Rencana Pembelajaran Semester (RPS) sesuai format baku dan standar mutu Universitas PGRI Ronggolawe (UNIROW) Tuban berbasis kurikulum OBE 2026.

🌟 Fitur Utama & Standar Mutu

1. Format Baku A4 Landscape (100% Sesuai Template Resmi)

  • Orientasi A4 Landscape penuh (w="16838" h="11909" dxa).
  • Margin halaman presisi: Atas/Bawah 39.6 pt, Kiri/Kanan 43.2 pt.
  • Tipografi elegan Cambria (Body 10.5 pt, Header 11 pt, Judul 12 pt bold).
  • Garis tabel single-line warna #B0B5B3 (0.5 pt) dengan padding sel proporsional.

2. Anatomi Dokumen Lengkap (4 Komponen Baku)

  • Tabel 0: Identitas, Otorisasi, CPL-CPMK & Korelasi (20 Baris): Memuat KOP resmi, Sub-CPMK berlabel taksonomi Bloom (contoh: [C4, A3]), dan tabel bersarang matriks korelasi CPL terhadap Sub-CPMK (18 baris).
  • Tabel 1: Silabus 16 Minggu: Sesi perkuliahan terstruktur dengan beban belajar SN-Dikti Permendikbudristek No. 53/2023 (UTS di Mg 8 & UAS di Mg 16 masing-masing bobot 25%).
  • Tabel 2: Rubrik Penilaian Holistik: 4 kriteria (Pemahaman Konsep 40%, Analisis Kritis 30%, Aplikasi Konteks Lokal 20%, Sistematika & Komunikasi 10%).
  • Bagian Evaluasi, Skala 7, Soal UAS & Lembar Pengesahan: Standar nilai A s.d. E (batas lulus C 56.00) dan 5 butir soal UAS berbasis HOTS.
Ketentuan Waktu Belajar SN-Dikti

- Tatap Muka (PB): sks × 50 menit/minggu.
- Penugasan Terstruktur (PT): sks × 60 menit/minggu.
- Belajar Mandiri (KM): sks × 60 menit/minggu.

🚀 Prasyarat & Instalasi

1. Prasyarat Sistem

Python 3.8+ dan library python-docx:

pip install python-docx

2. Pasang di Google Antigravity

git clone https://github.com/mariofahmi/skillISORPS.git .agents/skills/rps-unirow

💻 Cara Penggunaan

1. Melalui Chat AI

/rps-unirow buatkan RPS mata kuliah Hukum Tata Negara 4 SKS untuk Semester 3 kurikulum OBE 2026

2. Melalui CLI Python

py ".agents\skills\rps-unirow\scripts\build_rps.py"
